PROJECT 1
Embedded IoT • Full-Stack Web

Smart RFID Lab Locker System Using ESP32

Sistem otomatisasi peminjaman dan pengamanan inventaris laboratorium jaringan komputer.

C++ / Arduino ESP32 SoC PHP 8 Native MySQL REST API (JSON) RC522 RFID (SPI) Reed Switch Sensor Solenoid Actuator

Aplikasi perangkat lunak terintegrasi yang menggabungkan kontrol firmware pada mikrokontroler ESP32 dengan dashboard administrator berbasis PHP 8 dan MySQL. Sistem ini dirancang untuk mendigitalkan proses peminjaman alat laboratorium yang sebelumnya dilakukan secara manual.

Autentikasi menggunakan kartu RFID MIFARE untuk membuka solenoid door lock, sementara status pintu loker dipantau menggunakan sensor magnetik reed switch.

Setiap transaksi peminjaman dan pengembalian diverifikasi oleh server melalui REST API HTTP POST dengan payload JSON dan header X-Device-Token. Sistem juga mencatat latensi respons dan menyimpan arsip data.

Arsitektur sistem

IoT M2M + Web Client-Server

Protokol komunikasi

HTTP POST (REST API JSON)

Keamanan akses

Header X-Device-Token & Bcrypt

Pencatatan data

Database live & arsip + CSV

PROJECT 2
IoT • Web Monitoring & Remote Control

Web Monitoring Suhu AC & Remote Control

Dashboard pemantauan dan kendali AC dengan mode simulasi mandiri maupun koneksi ke server perangkat.

Python HTML5 CSS3 JavaScript HTTP API MQTT over WebSocket ESP32

Dashboard AC 1 PK untuk memantau suhu ruangan, set point, suhu luar, kelembapan, daya, konsumsi energi, dan perkiraan biaya, dilengkapi grafik riwayat suhu.

Kontrol tersedia melalui remote web untuk mengatur daya, suhu, mode, kipas, swing, turbo, sleep, dan timer. Aplikasi dapat berjalan dalam mode simulasi mandiri atau terhubung ke server Python dan perangkat ESP32.

Komunikasi server menggunakan HTTP API, sedangkan pemantauan status perangkat menggunakan MQTT melalui WebSocket.

Demo di portofolio berjalan dalam mode simulasi mandiri; koneksi ke server dan perangkat tersedia pada versi lengkap proyek.

Dashboard IoT AC dengan simulasi lokal

Pemantauan

Suhu, kelembapan, daya & grafik

Kontrol

Remote web dan server perangkat

Komunikasi

HTTP API & MQTT WebSocket
