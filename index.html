Smart RFID Lab Locker System Using ESP32

Sistem Otomatisasi Peminjaman & Pengamanan Inventaris Laboratorium Jaringan Komputer

C++ / Arduino ESP32 SoC PHP 8 Native MySQL REST API (JSON) RC522 RFID (SPI) Reed Switch Sensor Solenoid Actuator

Aplikasi perangkat lunak terintegrasi yang menggabungkan kontrol logika firmware pada mikrokontroler ESP32 dengan web dashboard administrator berbasis PHP 8 dan MySQL. Sistem ini dirancang untuk mendigitalkan dan mengotomatisasi proses peminjaman alat laboratorium jaringan komputer yang sebelumnya dilakukan secara manual.

Autentikasi fisik memanfaatkan kartu RFID MIFARE (13.56 MHz) untuk membuka solenoid door lock 12V secara otomatis, sementara status fisik pintu loker dipantau secara presisi menggunakan sensor magnetik reed switch.

Setiap transaksi peminjaman dan pengembalian diverifikasi oleh server pusat melalui protokol HTTP POST REST API dengan enkripsi header X-Device-Token, sekaligus mencatat metrik latensi respon sistem (dalam milidetik) ke dalam basis data dan arsip digital.
